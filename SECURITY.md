# Security

This repository contains no credentials and only aggregated public data. If you find a credential, a private workspace identifier or record-level personal data in the repository or its history, please report it privately through GitHub's **Report a vulnerability** feature on this repository rather than opening a public issue.

Databricks authentication uses the Databricks CLI profile store, and workspace configuration lives in untracked `conf/*.local.yaml` files. Neither belongs in version control.
